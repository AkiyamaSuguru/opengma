# 全知之眼 · 彼岸

一个纯静态网页：一只全知之眼围绕画框移动，注视画框里一个人的一生。打开 `index.html` 即可，不需要构建。

- **眼睛就是时钟**：每一幕，眼睛都会闭上，绕着画框移到新的位置再睁开（从左侧“升起”，到右侧“落下”）。它的眼神、瞳孔、血丝和颤抖会随剧情变化。不动鼠标时，它盯着故事的主角；移动鼠标，它会转过来看你。
- **九幕**：序幕·睁眼 → 降生（2041）→ 好奇（2048）→ 阶梯（2057）→ 选拔（2066）→ 升空（2069）→ 长夜（2069–2111）→ 彼岸（2111，比邻星 b）→ 终幕·凝视（2112）。
- **操作**：点击画框或按空格推进，← 回到上一幕，A 自动播放；底部时间轴可以直接跳到任意一幕。

文件：`css/style.css`（样式与动画）、`js/scenes.js`（各幕的 SVG 插画）、`js/app.js`（剧本、眼睛、转场、声音）。
