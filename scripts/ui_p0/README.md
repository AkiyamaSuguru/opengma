# UI P0：技术验证

这几个脚本用来验证界面方案中还不确定的几点，结果决定 P2（界面框架）的具体做法。它们不属于 GMA 库，验证完可以不合并到主分支。

应用要在 Windows、macOS、Linux 上使用，所以脚本只用一套做法，不为某个系统单独处理；三个系统上都可以运行。Mac 上的结果见 [RESULTS.md](RESULTS.md)。

所有命令都在仓库根目录运行。`--with` 只是临时装上需要的包，不会改动 `pyproject.toml`。

| 脚本 | 验证什么 | 命令 |
| --- | --- | --- |
| `p0_linechart.py` | Flet 原生 LineChart：大量数据点的流畅度、悬停读数、图例开关、横轴缩放、XPS 横轴反向 | `uv run --with flet-charts==1.0.5 python scripts/ui_p0/p0_linechart.py` |
| `p0_window.py` | 按可用屏幕区域比例的窗口尺寸、同一进程换窗、关闭工作区回到启动器 | `uv run python scripts/ui_p0/p0_window.py` |
| `p0_matplotlib.py` | 出版图预览：MatplotlibChart 与导出图片的对比 | `uv run --with flet-charts==1.0.5 python scripts/ui_p0/p0_matplotlib.py` |
| `p0_netcdf.py` | 含中文名称的项目文件能否写入并原样读回 | `uv run --with xarray --with "h5netcdf[h5py]" python scripts/ui_p0/p0_netcdf.py` |

### 一次运行全部

```bash
uv run python scripts/ui_p0/run_p0.py                     # 全部
uv run python scripts/ui_p0/run_p0.py window matplotlib   # 只运行其中几项：env netcdf tests linechart window matplotlib
```

依次记录系统信息、安装依赖、运行 NetCDF 检查和单元测试，再依次打开三个窗口（关掉一个才会打开下一个）。LineChart 和换窗两个窗口打开后会先自动测速（环境变量 `P0_BENCH=1`），测完停在那里，可以继续手动操作。按 Ctrl+C 停止整个运行。终端输出和测速结果都写入 `scripts/ui_p0/results/`：

| 文件 | 内容 |
| --- | --- |
| `env.log`、`netcdf.log`、`tests.log` 等 | 每一项的终端输出 |
| `linechart_bench.txt` / `.json` | 各组数据首次显示、缩放、平移、图例开关的用时（中位数）及原始记录 |
| `window.txt` | 可用屏幕区域、默认窗口尺寸、换窗用时 |
| `mpl_*.png` | 出版图对话框中导出的图片 |

LineChart 自动测速中每一步记两种时间：Python 端准备数据并发出更新的用时；以及界面回应探针的时间（发出更新后改变几个 1 像素控件的宽度，等界面回报尺寸变化）。界面在 60 秒内没有回应时，只记 Python 端用时。

## 窗口的通用做法

- **屏幕尺寸**：Flet 没有读取屏幕尺寸的接口。`p0_window.py` 在窗口透明时把它最大化一次，读出可用区域（去掉菜单栏、Dock、任务栏后）的尺寸再还原，三个系统同一段代码。
- **标题栏**：启动器和工作区都用系统标题栏，移动、缩放、关闭都是系统自己的操作。
- **换窗**：把窗口透明度设为 0，换好内容、尺寸并居中后再设回 1。不隐藏窗口：在 macOS 上隐藏唯一的窗口（`window.visible = False`）会让程序直接退出。
- **最小尺寸**：两个窗口共用一个最小尺寸，只在启动时设一次。换窗时改最小尺寸，有的系统会先按旧的最小尺寸调整大小（Linux 上从工作区回到启动器时窗口停在 960 × 640）。

## 在你的电脑上看的内容

### P0-1 LineChart

1. “XRD · 5 条叠加”、步长 0.01°（40 005 点）首次显示要多久？界面会不会卡住？
2. 在图上缩放、平移是否跟手？鼠标：滚轮缩放。触控板：捏合或双指上下滑缩放、双指左右滑平移。Flutter 把触控板手势当作缩放手势而不是滚轮事件，所以两种都接了；终端里会记下前几次收到的是哪种事件。窗口下方会显示每一步的耗时。
3. 悬停时提示框和下方的读数是否跟手？
4. 点击图例隐藏、显示曲线是否及时？
5. 步长改为 0.005°（每条 16 001 点）后，以上几项如何？
6. “XPS C1s”：横轴是否从高到低，刻度数值是否正确？
7. 关掉“曲线数据隔离更新”，缩放时慢了多少？
8. 打开“悬停提示带横轴值”后，首次显示慢了多少？
9. （可选）“显示点数”中的两种抽稀和“重新筛选点”，与默认的“全部（不抽稀）+ 只改范围”对比。

### P0-2 换窗

1. 读到的可用区域是否与屏幕相符（比屏幕略小，去掉了菜单栏、Dock 或任务栏）？
2. 启动器打开时是否居中；能否用标题栏移动、拖动边缘缩放？
3. 进入工作区、回到启动器时是否闪烁？用时多少？
4. 工作区中点标题栏的关闭按钮是否回到启动器；关闭开关后是否直接退出；在启动器中点关闭按钮是否退出？

### P0-3 出版图预览

1. 左右两边的字号、线宽比例是否一致？Times New Roman 是否正确显示？
2. 右边用触控板或滚轮缩放、拖动是否顺手？

### P0-4 NetCDF

终端最后一行是否为“全部通过”。
